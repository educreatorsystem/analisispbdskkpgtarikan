# Sistem Analisis PBD — Sekolah Kebangsaan Kpg. Tarikan

Versi asal tanpa PWA, untuk GitHub Pages.

## Penerbitan
1. Muat naik `index.html` ke root repository GitHub.
2. Buka **Settings → Pages**.
3. Pilih **Deploy from a branch** → `main` → `/(root)`.
4. Akses URL yang diberikan oleh GitHub Pages.

**Nota:** Lencana dipaparkan daripada pautan hos imej yang diberikan; paparan bergantung pada ketersediaan hos tersebut. Google Sheets perlu diterbitkan sebagai CSV dan Apps Script mesti diberikan akses yang sesuai. Jangan terbitkan data peribadi murid tanpa kelulusan dan kawalan akses yang wajar.
